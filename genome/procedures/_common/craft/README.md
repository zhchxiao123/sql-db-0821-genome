# 手艺库

`_common/craft/` 下的每个目录是一份**手艺(Craft Skill)**:教员工「这类活怎么干得好」。
它们由工序装载,在每个 Job 前物化到工作区。

**怎么写一份手艺,见 [`craft-authoring/SKILL.md`](craft-authoring/SKILL.md)。**
那份规范本身就是一份手艺——写手艺的员工装载它,人也读它。**内容只在那一处**:
在这里再写一遍,两处必然发散,而发散之后没人知道哪份是对的。

## 它们凭什么值得存在

判据不是「读起来有道理」,是挂与不挂这份手艺跑同一批任务,修复轮次与门禁一次通过率
有没有差别(见 `tests/drift/test_craft_ab.py`)。一份测不出差别的手艺应该删掉,
而不是留着占预算——同一句话对**改动**也成立,见 `genome/evolution/proposals.py`
的接受判据。
